# Проект 'data_bank_manager'
## Описание:
'data_bank_manager' - это программа для работы с банковскими данными
## Установка:
1. Клонируйте репозиторий
```
git clone https://github.com/AlexeyCherepkov/bank_develop.git
```
2. Установите зависимости 

- Установка poetry
```curl -sSL https://install.python-poetry.org | python3 -```
- Установка зависимостей
```poetry install```
## Работа с функциями
- ```masks``` имеет две функции для маскировки номера карты и номера аккаунта соответственно
- ```widget``` обрабатывает информацию как о картах, так и о счетах
- ```processing``` удаляет не соответствующие элементы списка и сортирует по дате
